# Site Institucional - Atividade HTML

## Descrição do Projeto
Este projeto consiste na criação de um site institucional simples utilizando apenas HTML. O objetivo é praticar a criação de páginas web, navegação entre páginas e organização de conteúdo.
## Estrutura do Projeto

```
├── index.html
├── servicos.html
├── contato.html
```
## Funcionalidades

### Página Inicial (index.html)

A página inicial apresenta:

* Nome da empresa como título principal.
* Menu de navegação com links para:

  * Serviços
  * Contato
* Imagem representando a empresa.
* Seção "Sobre a Empresa".
* Texto explicativo apresentando a empresa e suas atividades.

### Página de Serviços (servicos.html)

A página de serviços contém:

* Título "Serviços".
* Lista dos serviços oferecidos pela empresa.
* Aviso importante para os clientes.
* Link para retornar à página inicial.

### Página de Contato (contato.html)

A página de contato apresenta:

* Título "Contato".
* Informações de contato:

  * E-mail: [senai@gmail.com](mailto:senai@gmail.com)
  * Telefone: 61999999
* Tabela com horários de atendimento:

| Dia     | Horário        |
| ------- | -------------- |
| Segunda | 08:00 às 18:00 |
| Terça   | 08:00 às 18:00 |
| Quarta  | 08:00 às 18:00 |

* Link para retornar à página inicial.

## Tecnologias Utilizadas

* HTML5

## Objetivo

Desenvolver conhecimentos básicos em HTML, incluindo estruturação de páginas, utilização de links, imagens, listas, tabelas e navegação entre páginas.
