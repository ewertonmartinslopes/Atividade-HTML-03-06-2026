# ☕ Tech Grãos — Assistência Técnica

Projeto de um site institucional desenvolvido com **HTML5** para apresentar uma empresa especializada em manutenção e reparo de máquinas de café e equipamentos comerciais ou industriais.

O site possui páginas de apresentação, serviços e contato, com navegação entre elas.

## 📖 Sobre o Projeto

O projeto representa o site institucional da empresa fictícia **Tech Grãos**.

A empresa é apresentada como especializada em serviços de manutenção para:

* Máquinas de café;
* Equipamentos industriais;
* Equipamentos comerciais.

O site foi desenvolvido com várias páginas HTML conectadas por links internos.

## 🎯 Objetivos

Este projeto foi desenvolvido com os seguintes objetivos:

* Praticar a estrutura básica do HTML;
* Criar um site com várias páginas;
* Desenvolver links de navegação;
* Inserir imagens;
* Trabalhar com listas;
* Criar tabelas;
* Organizar informações institucionais;
* Apresentar serviços e dados de contato;
* Fortalecer os conhecimentos iniciais em desenvolvimento Front-end.

## 📄 Páginas do Projeto

### 🏠 Página Inicial

A página inicial apresenta:

* Nome da empresa;
* Imagem de apresentação;
* Descrição da assistência técnica;
* Links para as páginas de serviços e contato.

A página explica que a Tech Grãos trabalha com manutenção e reparo de máquinas de café e outros equipamentos.

---

### 🔧 Página de Serviços

A página apresenta os principais tipos de manutenção oferecidos:

1. Manutenção preventiva;
2. Manutenção corretiva;
3. Manutenção preditiva.

Também informa que os serviços precisam de agendamento prévio.

---

### 📞 Página de Contato

A página de contato apresenta:

* Telefone;
* E-mail;
* Endereço;
* Links de navegação;
* Tabela com os horários de atendimento.

Os horários são organizados por dia da semana, incluindo dias úteis, sábado e domingo.

## 🚀 Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/ewertonmartinslopes/html-site-assistencia-cafe.git
```

2. Acesse a pasta do projeto:

```bash
cd html-site-assistencia-cafe
```

3. Abra a pasta no Visual Studio Code.

4. Abra o arquivo:

```text
index.html
```

5. Execute diretamente no navegador ou utilize a extensão **Live Server**.
